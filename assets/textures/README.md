# Named theme WebP files

The original six WebP images are user-supplied on the `develop_dev.57` GitHub branch.
This code-update archive deliberately does not contain or replace those images.
When installing, MERGE this package into an existing module directory with
`assets/textures/` preserved; do not delete the installed module folder.

Expected files: gothic_arcane.webp, midnight_steel.webp, emerald_grove.webp,
royal_saphire.webp, crimson_ember.webp, sunlit_parchment.webp.
All six are unchanged in dev.60.
